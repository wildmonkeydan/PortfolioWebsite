About Me

Hi,
I'm Daniel Turner, a 3rd year at Sheffield Hallam University currently studying Computer Sciene for Games. I've been programming games for many years, starting with Scratch 1.0 which I picked up from my secondary school computing lessons.
I properly got into games programming in 2021, when I started programming in C so I could make a PS1 homebrew game, as it had been a dream of mine (I soon learned this was not the best way to learn C).
From there, I learned C++ at university and used this in my placement year at Feral Interactive, where I learnt to use scripting languages such as Ruby and Python.
I am currently working on an engine that will run on PC and PS5 as my final year project
